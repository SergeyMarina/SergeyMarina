## ИИ для бизнеса

- **Маркетинг и продажи:** поиск новых клиентов, работа с текущей базой, анализ отзывов и подготовка предложений.
- **Рекрутинг и HR:** поиск и оценка кандидатов, подготовка резюме и сопровождение воронки.
- **Операционные процессы:** обработка информации, подготовка документов и отчётов, автоматизация повторяющихся задач.

## ИИ для недвижимости

- улучшать фотографии объектов;
- создавать визуализации интерьеров;
- работать с клиентской базой.
